# Danish SpeedX 64x

A powerful Manifest V3 Chrome extension that controls HTML5 video playback speed from **0.25x to 64x**.

Danish SpeedX helps users speed through videos on YouTube, online courses, tutorials, and other HTML5 video platforms.

---

## Features

- ⚡ Playback speed control from 0.25x to 64x
- 🚀 Native playback support up to 16x
- 🔥 Turbo Mode for speeds above 16x
- 🎓 Smart Course Mode for learning platforms
- 🎥 Works with HTML5 videos
- ⌨ Keyboard shortcuts support
- 🌙 Premium dark popup interface
